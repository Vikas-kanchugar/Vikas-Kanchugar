## ✦ 02 — Featured Project

### 🤖 OffyAI | Local Code Assistant

A local-first code-assistant project exploring how language models can run on a personal computer.

**Project technologies and workflow described:**

- Qwen2.5 0.5B base model
- LoRA fine-tuning
- GGUF model export
- `llama.cpp` and `llama-server` deployment

The project explores local inference and privacy-conscious AI workflows. Its performance and capabilities should be evaluated from the actual implementation rather than assumed.
