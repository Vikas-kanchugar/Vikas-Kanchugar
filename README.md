## Featured Project

### OffyAI — Local Code Assistant

A local-first desktop AI project exploring code generation with a small language model. The goal is to experiment with private, offline-friendly inference rather than depend entirely on hosted AI services.

- **Base model:** Qwen2.5 0.5B
- **Fine-tuning:** LoRA adapter workflow
- **Model format:** GGUF export
- **Inference stack:** `llama.cpp` and `llama-server`
- **Focus:** Local inference, lightweight deployment, developer assistance
